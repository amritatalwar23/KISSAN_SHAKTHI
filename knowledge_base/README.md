# Agricultural Knowledge Base & RAG Repository

This directory contains verified agronomic publications, advisories, and the vector index used by the Kisan Shakti Retrieval-Augmented Generation (RAG) engine.

## Structure
- `documents/icar_advisories.json`: Curated and chunked advisories from ICAR institutes (IIHR, CPRI, IIMR, NBAIR).
- `index/`: Directory for persistent vector indices (FAISS/ChromaDB/TF-IDF matrix).

## Ingestion & Retrieval Pipeline
1. Documents are loaded with metadata (title, source institution, publication year, category).
2. Clean text chunks are generated by segmenting coherent paragraphs.
3. TF-IDF and dense vector representations are constructed.
4. Queries are matched using cosine similarity with a strict relevance threshold (0.18).
5. Responses include mandatory source attribution. If sufficient evidence is absent, the system informs the farmer rather than fabricating guidance.
