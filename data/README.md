# Kisan Shakti — Data Directory

This directory contains verified datasets, rule dictionaries, and directories used by the Kisan Shakti AI modules.

## Directory Structure
- `schemes/schemes.json`: Verified central and state agricultural support schemes (PM-KISAN, PMFBY, KCC, Soil Health Card, PMKSY, Raitha Siri, UP Kisan Uday).
- `crops/crop_rules.json`: Agronomic crop recommendation rules grounded in ICAR and State Agricultural University packages of practices.
- `experts/kvk_directory.json`: Verified directory of Krishi Vigyan Kendras (KVKs), Agricultural Research Stations, and the National Kisan Call Centre.
- `plantvillage/`: Reserved for local PlantVillage image subsets (Tomato, Potato, Corn/Maize).

## Data Licensing and Attribution
- **PlantVillage Dataset**: Publicly available under Creative Commons CC0 1.0 Universal Public Domain Dedication (Hughes & Salathe, 2015).
- **Government Schemes**: Curated from official government gazettes, `myscheme.gov.in`, `pmkisan.gov.in`, and `pmfby.gov.in`.
- **KVK Contacts**: Curated from the ICAR Agricultural Extension Portal (`kvk.icar.gov.in`).
